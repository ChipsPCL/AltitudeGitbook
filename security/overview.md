# Security Overview

Security is important across the Altitude ecosystem.

The Altitude token contract was audited by CryptoHub in November 2023. The contract remains unchanged since that audit.

Altitude's largest liquidity pool at the time of writing is Altitude/WETH on BaseSwap. This LP was sent to the burn address one year after launch and cannot be accessed ensuring there is always LP for trade.

Everest Vault has been fully audited by Contract Wolf with recommended fixes applied. 

{% hint style="warning" %}
Audits and automated scans reduce risk but do not eliminate it. Users should still treat all DeFi contracts as high risk.
{% endhint %}
